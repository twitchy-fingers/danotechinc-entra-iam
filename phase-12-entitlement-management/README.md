# Phase 12: Entitlement Management

> **Status: Planned.** This README outlines the scenario and scope. The full architecture, diagrams and `WALKTHROUGH.md` are added when the phase is built.

## Scenario

Requests for non-birthright access, such as Rachel Okafor's Finance team needing the payment approval tool or a contractor needing GitHub, arrive by chat today. They should be self-service, approved and time-bound.

## Planned scope

- Catalogues and access packages per department
- Multi-stage approval (manager, then resource owner)
- Expiry and extension rules; contractor packages tied to contract end date
- Governed guest access for partners
