# Phase 10: Non-Human Identities

> **Status: Planned.** This README outlines the scenario and scope. The full architecture, diagrams and `WALKTHROUGH.md` are added when the phase is built.

## Scenario

DanotechInc's pipelines and services authenticate with long-lived secrets. Siobhan Kelly's Data & AI team and Carlos Gutiérrez's DevOps team want secretless authentication.

## Planned scope

- Managed identities for Azure workloads
- GitHub Actions workload identity federation (no secrets in GitHub)
- Ownership and inventory of every service principal
- Conditional Access for workload identities
