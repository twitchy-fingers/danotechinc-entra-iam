# Phase 17: Compliance Mapping

> **Status: Planned.** This README outlines the scenario and scope. The full architecture, diagrams and `WALKTHROUGH.md` are added when the phase is built.

## Scenario

Two enterprise customers require SOC 2 Type II and ISO 27001 alignment. Nana Agyeman maps every control built in this program to the frameworks and assembles the evidence.

## Planned scope

- Control mapping: SOC 2, ISO 27001:2022, NIST CSF 2.0
- Privacy considerations: UK GDPR and Nigeria's NDPA
- Evidence index linking each control to `evidence/` artefacts
- Gap register and remediation plan
