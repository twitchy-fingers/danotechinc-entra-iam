# Phase 15: Identity Operations and Risk Analytics

> **Status: Planned.** This README outlines the scenario and scope. The full architecture, diagrams and `WALKTHROUGH.md` are added when the phase is built.

## Scenario

When ID Protection flags a risky sign-in for a London account executive, who investigates, what do they check, and how fast is access contained?

## Planned scope

- Risky user and sign-in triage process
- ITDR playbooks: token theft, MFA fatigue, consent phishing, compromised admin
- Operational runbooks (break-glass test, certificate rotation)
- Identity KPIs and risk trends
